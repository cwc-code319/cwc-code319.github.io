本机常驻 · ZeroTier 协作

离线说明 · 非实时状态

同一个服务，两个访问入口。Windows 管理后台进程，Codex 用来开发；队友通过已授权的 ZeroTier 网络访问。

先说明边界：关闭 Codex 不等于关闭后台服务；电脑关机、睡眠或断网后，仍然无法访问。登录自启解决的是恢复运行，不是关机期间持续在线。

.\service-control.bat status

不使用旧的 access-control 同时启动另一个实例。关闭不会清空数据库；同一组地址连接的是同一个业务服务。

03队友访问检查

不要求连接同一热点
  1. 双方安装 ZeroTier，加入同一网络，确认队友设备已获授权。
  2. 你的电脑保持开机、联网，ZeroTier 正常运行，后台服务处于开启状态。
  3. 队友打开 10.92.209.60:8765；如使用代理软件，对这个地址设置直连。
  4. 打不开时，先在队友的 PowerShell 测试 TCP 端口。若失败，检查成员权限、ZeroTier 流规则、链路和双方防火墙。
在队友电脑执行
Test-NetConnection 10.92.209.60 -Port 8765
已配置的防火墙范围与身份边界

本轮新增入站规则仅允许指定 pythonw.exe 的 TCP 8765、目的地址 10.92.209.60、来源网段 10.92.209.0/24；未新增 WLAN 任意来源开放规则。没有关闭 Windows 防火墙。

当前全网卡／ZeroTier 模式不启用应用账户登录，只面向可信网络。请求令牌和 Host 校验不是身份认证；不要做路由器公网端口转发。公网部署需要另行配置 HTTPS 与账户保护。

哪些情形仍可访问？

  • 关闭 Codex系统托管

    后台进程不依赖开发终端；电脑与网络仍须正常运行。

  • 开机后登录当前用户已配置自启

    需要先启用服务。主动 close 后不会自动恢复，需再次 open。

  • 关机、睡眠、休眠或注销不可访问

    本机不能在断电或用户会话终止后继续提供服务。

  • 断网或 ZeroTier 退出队友不可访问

    本机访问与外部网络连接是两回事。
